# Offline snapshot rebuild (limited)

`bun run snapshots:rebuild --season YEAR` reads the **existing** SQLite tables from `DATABASE_PATH` (default `chars.sqlite`) and writes content-addressed artifacts and a last-successful manifest under `CHARS_CACHE_PATH/snapshots/YEAR` (default `.cache`). `.cache` is ignored by git. No migrations or schema changes are required. Consumers must read `current.json` first and then only its listed keys; a failed rebuild does not change the manifest. Store the cache on durable storage if snapshots must survive a restart. There is no cross-process lock or transaction coupling source writes to rebuilds yet.

Without trusted metadata, score pairs are **not** proof of completion; games are treated as scheduled, and coverage reports unverified classification/completion. Optional `.cache/source/YEAR-games.json` is an object keyed by decimal game ID with `SourceGameMetadata` fields (`providerSeasonType`, `applicationGameType`, `classificationSource`, `status`, `completed`, `payloadHash`). This file must come from a validated source, not guessed from scores. The existing games table is contractually regular-season-only, but metadata may further exclude a CCG or bowl. No field in the existing schema can distinguish an unfinished 0–0 from a tie. Source metadata is currently operator-supplied; no CFBD importer is included.

An optional `.cache/source/YEAR-calendar.json` has `freezeUtc`, `firstCcgUtc` (ISO UTC strings), and `verified: true`. A final is emitted **only** if these cutoffs are ordered, membership/schedule/classification and completion coverage have no unresolved warnings, and a nonempty contemporaneous CFP (2014 onward) or AP (earlier) release occurs between freeze and CCG. `verified` is an operator assertion, not a conclusion from the database. Do not mark a calendar verified without checking the full season schedule against an authoritative source. Missing or stale polls are disclosed in weekly coverage; 2014+ weekly views use the latest available AP poll when CFP is not yet released, but finals do not. No later poll or game result enters an earlier weekly calculation. Historical weekly reconstruction uses kickoff and poll-release timestamps, **not** the provider's historical observation times. Partial live weeks and exact completion-time isolation are not supported. The absence of a scenario proof is always `pending`, never an elimination claim.
