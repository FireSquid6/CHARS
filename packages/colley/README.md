# Colley selection engine

`chars-colley` is a pure TypeScript package. It does not query the database, contact a server, or modify the existing CLI. Import `validateInput`, `buildSnapshot`, `calculateSelection`, or the individual calculation stages from `chars-colley`. `analyzeScenarios(snapshot, snapshot.remaining, { type: "conservative" }, { maxCompletions: 10000 })` enumerates future results and eligible-poll permutations. Tests use synthetic inputs only: `bun test packages/colley/tests`.

The normalized `Input` contract is declared in `src/types.ts`: season-specific teams (including individual non-FBS opponents), games with ISO UTC timestamps, regular/postseason classification and explicit completed/scheduled/cancelled statuses, AP/CFP releases with poll-specific week/ranks, explicit end-of-last-full-regular-season-weekend `terminalCutoff`, and three source-completeness assertions. A scheduled game's scores must be null. Completed games are deduplicated by ID; conflicting duplicates fail. Call `buildSnapshot(input, cutoff)` with an ISO UTC timestamp no later than `terminalCutoff`. A third `associatedPollId` argument explicitly associates a poll released *after* the game cutoff with that snapshot (e.g. a Tuesday CFP release for the preceding Sunday); the adapter is responsible for validating the reference date. Snapshot calculations reject incomplete membership, schedule, poll or already-due unresolved games. Subsequent results/polls do not enter an earlier snapshot unless explicitly associated by the caller. Caller must establish that the declared cutoff and completeness assertions accurately describe the source; this library cannot infer missing games or conference dates from scores alone.

The default `fbs-only-1` model uses `ml-matrix` Cholesky solving for every snapshot, checks the max absolute equation residual (1e-9), and resolves comparisons within 1e-9 of a threshold/tie using exact rational Gaussian elimination with `fraction.js`. This 1e-9 window is **only** a trigger for exact comparison, never an eligibility or selection epsilon. Eligibility uses integer arithmetic. Full FBS matrix ratings include ineligible teams; FCS games affect records but not the matrix. Ratings are unrounded in results. `colley-fbs-1` is the selection policy: all cyclic SCC internal edges are suppressed (not just three/four-team cycles), outsider-to-bid jumps are forbidden, and play-in winners inherit fixed bracket slots. The outputs retain source poll, initial routes, suppressed edges, swap log, raw and adjusted ranks, bracket alternatives and input SHA-256 hash. The returned snapshot includes the validated normalized source; do not present it as a compact export.

Scenario proofs are **exhaustive only**, not estimates. The default conservative model permits every distinct ordering of up to 25 eligible FBS teams; older games allow ties only when `tiesAllowed` is true. `{ type: "frozen", poll }` is a *conditional* analysis. Each evaluated leaf uses one result per shared game, reruns the entire engine and saves witnesses. A reached budget leaves unproved statuses `null` and `proofState: "pending"`; impossible best records can still prove elimination. An exhaustive coverage gap receives `policy_exception`. The entire schedule is assumed fixed, with no future additions/cancellations. Large schedules/poll universes are computationally infeasible with this version: no branch-and-bound, factorization reuse, persistence or resumable work is provided. Do not treat `pending` as an elimination or a proof. No SQLite adapter or CLI wiring is included in this package.
